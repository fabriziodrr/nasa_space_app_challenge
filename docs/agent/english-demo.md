# English demo

The demo interface, browser speech recognition and playback use English. NVIDIA conversation replies, operational reports and private logbook drafts are instructed to use English even when an input message uses another language. The deterministic mock supports explicit English check-ins and retains historical Italian input support.

Operational discrepancies compare the same quantity over a comparable period. Reported fatigue cannot be labeled inconsistent with REM duration, HRV or sleep efficiency without explicit validated comparison criteria. Their relationship is described as an uncertainty instead.

Start a new session after updating the server to see the new language. Existing messages, reports, diaries and user-entered activity titles remain stored in their original language; they are not rewritten. Original built-in demo activity names are displayed in English in the schedule view.
