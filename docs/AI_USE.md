# SLOTH — AI / SI disclosure

AI tools were used to assist code development, debugging, documentation, synthetic demonstration data, visual assets and presentation/video preparation. The project includes generated branding and a mascot. The assistant generates responses, reports and schedule suggestions using its configured language model. Speech is synthesized by browser speech synthesis or the configured server provider; it is not a human voice recording.

The team integrated and tested the prototype. Synthetic crew and sensor data are illustrative, not real astronaut measurements. Webcam observations and user statements remain separate inputs. Scientific references do not validate generated medical claims or custom thresholds.

## Submission text
